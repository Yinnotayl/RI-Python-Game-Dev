## Hewwo

Some random games here, first off install `python` version 3.13 i think.
then do

```pwsh
pip install pygame
```

to install pygame.

To play these games just do the following:




**3D Cube:** [`3d cube V2.py`](https://github.com/Yinnotayl/RI-Python-Game-Dev/blob/main/3d%20cube%20V2.py "3d cube V2.py")

This is a random 3d cube where you just point around and slime out mini cubes.

Right click to attack, left click to absorb which makes you invincible but reduces your score.

Enemies spawn more as your score increases, and they take time depending on your angle to die.




**Simple platformer:** [`game1V2.py`](https://github.com/Yinnotayl/RI-Python-Game-Dev/blob/main/game1V2.py "game1V2.py")

A simple platformer, arrow keys to move, z to jump, x to attack and shift to crouch and pass through blue platforms :).




**PKO alpha:** [`Platform Knockout (aka LAN MELEE)/`](https://github.com/Yinnotayl/RI-Python-Game-Dev/tree/main/Platform%20Knockout%20\(aka%20LAN%20MELEE\) "Platform Knockout (aka LAN MELEE)")

This is a multiplayer version of **Simple platformer**. To play, download the folder, and open/unzip it, then run [`main.py`](https://github.com/Yinnotayl/RI-Python-Game-Dev/blob/main/Platform%20Knockout%20\(aka%20LAN%20MELEE\)/main.py "main.py") using `python main.py`




have fun!!
